游戏退出 / Windows 重启：只读诊断

1. 在发生问题的 Windows 虚拟机中双击 01-Audit.cmd。
2. 等待窗口显示 Saved，桌面会出现 G11-GameExit-日期-编号 文件夹。
3. 先打开 summary.txt；report.json 保存了完整事件字段和当前资源信息。
4. 若出现 WARNING，请保留报告；“读不到”不能当作“没有错误”。

工具不修改系统、游戏、驱动、BCD、分页文件或服务，不启用测试签名。
不读取游戏进程内存，不上传报告。报告含本机路径、账户名等事件原文，请私下提供。
无须回滚；用完关闭窗口即可。删除报告只会删除这次采集的副本。

注意：事件 41/6008 说明 Windows 非正常重启，不能单凭它确定触发者。
重启后的空闲内存不是闪退时的内存；没有 DNF 崩溃事件也不代表没有退出。
宿主 QMP 观察和完整中文教程见 deploy/docs/G11-GAME-EXIT.md。
